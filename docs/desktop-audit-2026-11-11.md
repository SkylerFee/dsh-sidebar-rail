## 发现的问题

### F1：取数未完成时切换工作区与任务，列表永久加载（P2，本次引入）

位置：`src/client/hooks/use-remote-list.ts:73–80、112–118`。`b224ffa` 将任务列表扩展为 `when: ['tasks', 'workspace']`。

复现：让 `catalog()` 在切换后才返回；打开工作区后，在取数完成前直接切到任务。`open` 变化触发旧 effect 清理，设置 `live=false` 并清除超时；新 effect 因 `active=true` 且 `started.current=true` 提前返回。旧答案无法落地，新请求没启动，5 秒超时也消失。

执行当前源码的固定替身结果：

```text
初开工作区：phase=loading, calls=1, timers=1
直接切任务：phase=loading, calls=1, timers=0
成功答案返回：phase=loading, calls=1, timers=0
关闭再打开：phase=ready, calls=2, timers=0
```

用户可关闭后重开恢复。会话列表本身不依赖这个结果，但时钟可能缺失。**这是离线受控复现，本轮未人为制造真实慢网络请求**。

### F2：Escape 回焦后自动重开（P2，既有问题，真机已复现）

位置：`src/client/components/RailColumn.tsx:489–493` 与 `RailSurface.tsx:119–122`。

Escape 先 `retract()`，再 `trigger.focus()`；按钮 `onFocus` 又安排打开。离线结果为 `open=null → pending timer=120ms → open='tasks'`。真机将暂停/结束分类展开后按 Escape，浮层短暂关闭，随后以默认折叠状态重新打开。该路径在 `fd670d7` 已存在，不归因于本次焦点修正。

### F3：浮层未启用全高模式（P2，既有规格落差，真机已确认）

位置：`src/client/components/flyouts.tsx` 的工作区、任务、插件 `shell()` 调用，及 `flyout-shell.tsx:91–107`。

调用仅传第六参数 `sections=true`，未传第七参数 `topFlush=true`。受控渲染任务浮层得到 `top=98px、maxHeight=790px` 且没有 `height`。真机 1236×814 截图中，任务浮层默认从 **y≈98 到 y≈371**；展开两类空态后底边变为 **y≈491**，高度随内容增加约 120px，且没有贴到窗口底部。工作区顶边约 58px、插件顶边约 138px，也随图标锚点变化。

这些数值来自 1:1 窗口截图，不冒充 DOM 外框测量。当前账号浮层的只读 DOM 查询为 `x=64、y=584、width=290、height=218、bottom=802`；它属于底部对齐的独立浮层。历史 K3「全高外框越界 2px」的同场景复测未完成，不宣称已修。

### F4：默认收起分区首次点击无效（K2，既有问题，真机已复现）

位置：`src/client/hooks/use-flyout.ts:170–171`。未设值项首次写入 `folded=true`，与其默认收起状态相同。真机暂停分类首次点击 AX 内容无变化，第二次显示空态；结束分类同样需点两次。本轮保留既有 todo，没有修复实现或放宽断言。

### F5：任务时钟在行尾，未达到行首规格（P3，本次新增能力的规格落差）

位置：`src/client/components/primitives.tsx` 的 `Row()`。标题容器先于 `SessionMarkCell`，样式未调整两者顺序；真实最近列表截图中，时钟在最后一行的右端。与 `spec-0.4.0-session-list.md` 要求的行首 16px 格不一致。使用说明已按当前事实写成行尾，规格差异保留在此。

时钟在真实数据下可见，但所有运行/未读/待操作状态与时钟互斥的瞬时表现、点击时钟不导航，本轮只有源码和单测依据，没有逐项真机操作证据。

### F6：添加项目仍未跑通（P2，既有真机问题仍可见）

通过工作区「添加项目」按钮尝试目录选择，浮层随后收起，没有看到可用的目录选择器。稍后重新打开浮层，AX 与画面均出现：

> 添加项目失败，可展开侧栏用宿主的添加按钮重试

未选择目录，未创建或登记新项目；成功选择、取消和登记失败三条路径未通过真机验收。源码层保留成功目录值的修复不等同于整个 Desktop 链路已成功。本轮没有足够日志定位后台失败原因，不推断成某个确定的后端根因。
