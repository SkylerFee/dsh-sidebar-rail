# 0007 浮层改为单一滚动容器，撤销分区独立滚动与 1/3 限高

- 状态：已采纳（2026-11-10）
- 取代：[ADR-0004](0004-sectioned-flyout.md) 的「分区独立滚动 + 每区 1/3 限高 + 标题固定」三件事。ADR-0004 的另一半——「浮层占满可用高度、高度不随内容与条数变化」——在本 ADR 里被标注为继续有效，但该条**实际从未落地**（TS 迁移漏传 `topFlush`）；其现状与取舍由 [ADR-0008](0008-flyout-height-follows-current-build.md) 修正。
- 相关：`.dsr-sections` / `.dsr-section` / `.dsr-section-body` 系列样式、`src/client/model/geometry.ts` 的 `sectionMaxHeight` / `sectionBudgetFor` / `SECTION_HEIGHT_RATIO`、[spec-0.4.0](../spec-0.4.0-native-parity.md)

## 背景

0.4.0 把浮层改成「三分区」，每个分区是**固定标题行 + 独立滚动内容区**，并有**可用高度 1/3 的上限**（ADR-0004）。当时的理由是：三个分区内容长短不一，各自限高加独立滚动能让它们在视觉上大致均衡，且不让某一个长列表撑满整块面板。

这套结构在真机上暴露了两个问题：

1. **列表被切碎**。同一个浮层里并存多个滚动区，用户滚动时要在几块各自滚动的小窗之间来回找位置，指针落错区域就滚错地方。
2. **与宿主习惯相反**。宿主自己的侧栏、以及 2026-11-10 实测的 Codex 侧栏，都是**一个整体滚动区**：分组只是标题，分隔靠留白而不是横线，滚动时整页一起动、标题跟着滚走。插件浮层的三段式横线 + 三个滚动条，读起来像「三块表格」，而不是宿主的一部分。

0.4.0 的目标是「看起来、用起来都像宿主自己的一部分」。这个目标与分区独立滚动直接冲突，因此需要一次**显式的决策反转**——不留记录的话，未来会有人把这次简化当成回归。

## 决定

1. **浮层内容改为单一滚动容器**。分区的标题与条目都进同一个滚动流；不再有分区各自的 `overflow` 区域。
2. **删除分区之间的分隔线**。分组靠标题行的字重与留白区分，不用 `border-top`。
3. **删除 1/3 限高**。`sectionMaxHeight` / `sectionBudgetFor` / `SECTION_HEIGHT_RATIO` 一并删除，不保留空壳——限高取消后它们不再有消费者。
4. **分区标题随内容滚动**。这是本次最直接的取舍：放弃 ADR-0004 的「标题固定」。整页滚动意味着标题会滚出视野。
5. **保留 ADR-0004 的另一半**：浮层高度仍钉死为「`--dsh-frame-top-clearance` 之下到窗口底」，**不随内容长短与 `recentCount` 变化**。这条性质与滚动结构无关，且是 0.3.2 修掉的缺陷（浮层高度跳动）的防线，不撤销。
   - **2026-11-11 修正**：这条在本轮实现中并未真正生效——三个分区浮层漏传 `topFlush`，实际按锚点摆放且高度随内容。见 [ADR-0008](0008-flyout-height-follows-current-build.md)。
6. **保留分区可折叠**：分区仍能展开/收起，收起时内容卸载；折叠状态仍不持久化。

## 后果

- 浮层里只有一个滚动条，滚动行为与宿主侧栏一致。
- 「最近会话」这个分区标题在长列表里会滚出视野。**缓解**：最近会话条数的步进器在浮层的**固定底栏**，不参与滚动，因此用户滚到哪里都能找到它。
- 分区收起/展开仍然**不影响浮层总高度**（第 5 条决定的效果）：收起只是让滚动内容变短，不改变面板高度。
- 删掉三个几何函数后，`geometry.ts` 只剩浮层定位与轨唤出判据；相关单测同步删除，不保留对着已删能力写的断言。
- 与 ADR-0004 的对比读法：ADR-0004 解决的问题（浮层高度不随内容跳动、不覆盖 chrome 带）依然被解决；它引入的**分区滚动结构**被本次推翻。

## 不要做什么

- 不要改回分区独立滚动，也不要给分区重新加限高。碎片化滚动是被实测否决的，不是被忘记的。
- 不要为了找回「标题常驻」而引入 sticky header。已在 [spec-0.4.0](../spec-0.4.0-native-parity.md) 的决策记录里明确否决：多段标题叠粘与宿主观感不同，实现复杂度也不成比例。
- 不要因为「整页滚动」就去掉固定底栏。底栏是标题滚走之后仍能找到条数设置的前提。
- 不要删除 ADR-0004 的历史理由。它记录的是「两 pane → 三分区」那一步的正确取舍，本 ADR 只说明其中三条在 0.4.0 不再成立。
