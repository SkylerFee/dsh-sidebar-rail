# 0.4.0 规格：浮层分区化

> 状态：设计已确认（grill 完成），待拆票实现
> 决策记录：[GLOSSARY.md](../../GLOSSARY.md)、[ADR-0004](../adr/0004-sectioned-flyout.md)、[ADR-0005](../adr/0005-host-public-api-boundary.md)

## 1. 目标

把三个浮层（工作区、定时任务、插件）改成分区结构，并给工作区加「项目展开会话」与「添加项目」能力。

**不含**：TypeScript 化（决定保持零构建手写 JS）。

## 2. 共同结构

每个分区 = **固定标题行 + 独立滚动内容区**，分区之间用 `--dsw-alias-border-l1` 分隔。

浮层高度：**占满可用高度**，从 `--dsh-frame-top-clearance` 之下到窗口底，不再用视口 70%。

分区高度上限：**可用高度的 1/3**，超出各自滚动；内容不足 1/3 不强行撑满。

展开/收起状态：**一律不持久化**，每次打开浮层都是默认状态。

## 3. 工作区浮层

### 3.1 三分区

| 顺序 | 标题 | 内容 | 默认 |
| --- | --- | --- | --- |
| 1 | 置顶 | 被置顶的项目 | 展开 |
| 2 | 项目 | 其余全部项目（宿主顺序） | 展开 |
| 3 | 最近会话 | 全部工作区的最近会话 | 展开 |

- 项目只出现在一处：置顶后从「项目」区移除。
- 「项目」区标题行右侧有**添加项目**按钮。

### 3.2 项目行

每行：`[展开箭头] 项目名 [图钉] [新建会话]`

- 展开箭头：始终显示；无会话时仍可展开，展开后显示空态文案。
- 展开内容：该项目下的会话列表
  - 排序：宿主顺序
  - 条数：**不限**
  - 过滤：**不过滤**（归档、空白、子代理都列出）
  - 点击会话：打开该会话，收起浮层
- 图钉：切换置顶，持久化到 `localStorage['dsh.sidebar-rail.v1'].pinnedWorkspaceIds`
- 新建会话：始终显示。调用 `uiWorkspace.startSession(workspaceId)`，跳转并收起浮层。

### 3.3 添加项目

点「添加项目」→ `uiWorkspace.pickDirectory()` → 用户选定 → `workspaces.create({ path })` 登记 → **留在浮层，不跳转、不建会话**。

用户取消（返回 `null`）时静默返回，不报错。

### 3.4 最近会话分区

保持现状：`updatedAt` 倒序、受 `recentCount` 限制、排除归档/空白/子代理、显示状态标识。底部保留条数步进器。

## 4. 定时任务浮层

| 顺序 | 标题 | 宿主状态 | 默认 |
| --- | --- | --- | --- |
| 1 | 进行中 | `active` | 展开 |
| 2 | 已暂停 | `paused` | 收起 |
| 3 | 已结束 | `ended` | 收起 |

- 数据源：`remote.schedule.catalog()`（返回全部状态）。
- 空分区：保留标题 + 空态文案。
- 点击条目：打开定时任务面板（`selectPanel('schedules')`），**不定位到具体条目**（详见 ADR-0005）。
- 底部保留「打开面板」。

## 5. 插件浮层

| 顺序 | 标题 | 判据 | 默认 |
| --- | --- | --- | --- |
| 1 | 已启用 | `enabled === true` | 展开 |
| 2 | 未启用 | `installed === true && enabled === false` | 展开 |

- 数据源：`pluginManager/listBundles`。
- 「未启用」**不含**尚未安装的官方按需插件。
- 点击条目：打开插件管理面板。**不提供开关**。
- 每个条目显示包名与版本（现状）。

## 6. 数据与刷新

- 任务、插件列表：**每次打开浮层重新拉取**（沿用 `loadRemote`），5s 超时进入失败态。
- 项目与会话：来自标准 hooks（`useWorkspaces` / `useSessions`），随宿主快照实时。
- 账号：维持现状（挂载时读一次，不订阅）。

## 7. 硬约束（不可违反）

1. 只通过 `shell.overlay` 增量注册，不替换 `sidebar` 槽。
2. 不引入构建步骤、不加依赖（ADR-0002 保持不变）。
3. 浮层不覆盖顶部 48px chrome 带。
4. 只使用宿主公开 API（ADR-0005）。
5. 分区标题行不得随内容滚动。

## 8. 验收清单

| # | 用例 | 预期 |
| --- | --- | --- |
| B1 | 打开工作区浮层 | 三个分区，各有固定标题；浮层占满可用高度且不盖红绿灯 |
| B2 | 滚动任一分区内容 | 该区标题行不动，其他区不动 |
| B3 | 某区内容很少 | 该区不高过可用高度 1/3，不平白撑满 |
| B4 | 收起/展开分区 | 只影响该区可见内容，浮层总高度不变 |
| B5 | 展开一个项目 | 显示其全部会话（含归档/空白/子代理），宿主顺序，不限条数 |
| B6 | 展开一个空项目 | 显示空态文案 |
| B7 | 点击项目下会话 | 跳到该会话并收起浮层 |
| B8 | 点新建会话 | 在该项目下建会话，跳转并收起浮层 |
| B9 | 点添加项目并选定目录 | 登记为新项目，仍在浮层；取消则无变化 |
| B10 | 置顶项目 | 从「项目」区移到「置顶」区；刷新后保持 |
| B11 | 任务浮层 | 三区；进行中展开，另两区收起；空区显示空态 |
| B12 | 点任务条目 | 打开任务面板 |
| B13 | 插件浮层 | 已启用/未启用两区；未启用只含已安装但关闭的 |
| B14 | 关闭重开浮层 | 全部回到默认展开状态 |
| B15 | 窄窗（<768px）/ 展开态 / Web | 轨不渲染，行为与 0.3.x 一致 |

## 9. 不做什么

- 不做 TypeScript 化。
- 不做会话级置顶（宿主有 `pinSession`，本项目不用）。
- 不做任务详情定位。
- 不做浮层内插件开关。
- 不持久化分区/项目的展开状态。
