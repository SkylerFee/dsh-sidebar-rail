# dsh-sidebar-rail · 产品需求说明（PRD）

> 本文件与项目内其他文档均保存在 `dsh-sidebar-rail/` 目录下，不在上层目录散落。

## 1. 背景

DSH 折叠左侧栏后是一条 56px 图标轨，但轨内只有品牌标、可扩展的面板图标（当前仅「定时任务」「插件」两个）与底部设置，**没有工作区入口，也没有悬浮列表**。Codex 桌面端的折叠侧栏则是一排常驻功能图标，悬浮即展开对应列表，用户可以完全不展开侧栏完成大部分导航。

本插件把 DSH 的折叠态改造成 Codex 风格的常驻图标轨，同时**保持展开态为 DSH 原有形态**（品牌行、新会话、工作区/会话浏览、设置），避免用户已有的操作习惯被打断。

## 2. 目标与非目标

### 目标
1. 折叠态 = 常驻图标轨：工作区、定时任务、插件、更多始终可见；底部为**用户头像**图标。
2. 悬浮图标 → 展开对应列表浮层（工作区列表 / 定时任务列表 / 已启用插件列表 / 账号信息与设置）。
3. 工作区支持**置顶**，并按 `置顶项目 / 普通项目 / 最近会话（最近 10 条）` 分组显示。
4. 展开态恢复 DSH 原有逻辑，并保留工作区分组显示。
5. 展开/折叠状态**持久化**，下次启动保持退出前状态。

### 非目标
- 不改宿主侧数据模型（不改 `packages/*`，不新增 RPC）。
- 不改展开态下工作区/会话浏览器的既有交互（新建、重命名、归档、Fork 等仍沿用宿主实现）。
- 不实现 Codex 的活动视图、自定义分区、永久删除。
- 不动右侧栏（right sidebar）。

## 4. 交互规格

### 4.1 折叠态（rail）

```
┌──────┐
│  🗂  │  工作区
│  ⏱  │  定时任务
│  🧩  │  插件
│  ⋯  │  更多
│      │
│  👤  │  用户头像（底部固定）
└──────┘
```

- 图标尺寸 20px，按钮 36×36，垂直间距 4px，左右居中。
- 悬浮 120ms 后展开浮层；移出图标与浮层共同区域 200ms 后收起（防抖，避免鼠标穿越间隙时闪断）。
- 浮层锚定在轨右侧，宽度 280px，最大高度 `calc(100vh - 32px)`，内部滚动。
- 点击图标：工作区 → 先确保侧栏展开（DSH 原生展开逻辑）；定时任务/插件/更多 → 选中对应主面板。
- 键盘：图标可 Tab 聚焦；聚焦后 Enter 触发点击，`Escape` 关闭浮层；箭头上下在浮层内移动。

### 4.2 展开态（wide）

沿用 DSH 原有结构：品牌行（logo + 名称 + 版本徽标）→ 新会话按钮 → 面板图标行 → 工作区/会话浏览区 → 底部设置（+ 插件动作位）。

新增：工作区列表按 `置顶项目 / 普通项目 / 最近会话` 三段分组；段标题为小号灰字；置顶项目行右侧有「取消置顶」按钮，普通项目行悬浮显示「置顶」按钮。

### 4.3 分组规则

| 段 | 规则 | 排序 |
| --- | --- | --- |
| 置顶项目 | `pinnedWorkspaceIds` 命中的工作区 | 置顶时间倒序（最近置顶在前） |
| 普通项目 | 其余工作区 | 宿主返回顺序 |
| 最近会话 | 全部工作区中未归档的会话，按 `updatedAt` 倒序，**最多 10 条** | 时间倒序 |

- 某段为空时不渲染该段（不占位、不显示空标题）。
- 置顶状态存在浏览器 `localStorage`（键 `dsh.sidebar-rail.v1`），不写宿主数据。

### 4.4 状态持久化

- 键：`dsh.sidebar-rail.v1`，值形如 `{ "collapsed": true, "pinnedWorkspaceIds": ["ws_x", "ws_y"] }`。
- 侧栏挂载时读取；若与当前框架状态不一致，调用一次 `ctx.layout.toggleSidebar()` 校正（模块级 guard 保证只执行一次）。

## 5. 约束

- 纯 Client 插件：不新增宿主路由、不改 profile 之外的状态。
- 只使用 `--dsw-alias-*` 主题 token，不写死颜色（图标 artwork 除外）。
- 不使用 `@deepseek-ai/dsh-client-ui-primitives` 等宿主包模块；自绘控件并复刻宿主样式与可访问性属性。
- 组件崩溃不得影响宿主：错误边界兜底，降级为 DSH 默认侧栏样式（仅渲染最小骨架）。

## 6. 验收清单

| # | 用例 | 预期 |
| --- | --- | --- |
| A1 | 收起侧栏 | 出现 5 个图标（4 功能 + 头像），无文字 |
| A2 | 悬浮工作区图标 | 浮层分三段显示，最近会话 ≤ 10 条 |
| A3 | 悬浮延时 | 快速划过图标不弹浮层；停留 120ms 才弹 |
| A4 | 点击置顶按钮 | 项目移入「置顶项目」段；刷新后仍在 |
| A5 | 展开侧栏 | 与 DSH 原有布局一致，工作区仍分组 |
| A6 | 重启客户端 | 折叠状态与退出前一致 |
| A7 | 键盘导航 | Tab 可遍历图标，Escape 关闭浮层 |
| A8 | 主题切换 | 亮/暗色下浮层与图标颜色正确 |
| A9 | 无工作区/无会话 | 对应段不渲染，浮层显示空状态文案 |
| A10 | 插件卸载 | 侧栏恢复 DSH 默认形态，无残留样式 |
