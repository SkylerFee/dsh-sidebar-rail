## 图片与功能

下表各功能均有 `-light.png` 和 `-dark.png` 两张图，尺寸为 **360×766**。完整图标轨始终保留；浮层上下边界不裁断，长列表用顶部与滚动末尾两种场景补齐。

| 文件前缀 | 截图内容 | 边界 |
| --- | --- | --- |
| `workspace` | 工作区标题、置顶 / 项目 / 最近会话分组、文件夹、图钉、新建与添加项目入口 | 最近列表后半段在 `recent` 图中 |
| `project` | 展开文件夹、10 条项目子会话、项目「显示更多」及后续项目分区 | 仅当前窗口可视部分，不拼成长列表假截图 |

## 裁切与脱敏

- 从原始窗口提取完整图标轨和浮层；遮蔽其他主页面，避免泄露会话正文。短浮层下方保留空白，展示当前真实高度。
- 只模糊业务名称、会话/任务标题及金额；分组标题、时间、版本、图标与操作文案保持真实。未重绘控件或把规格图当实机截图。
- 原始窗口图、联系表及 npm 缓存已按用户选择清理；处理脚本、离线复现与打包清单保留在仓库 `tmp/output/acceptance-2026-11-11/`，不作为发布内容。文档只使用本目录的 18 张脱敏图。
- 截图覆盖当前场景，不表示所有状态通过。异常、取消、慢请求、未登录账号与其他平台的边界以验收报告为准。
